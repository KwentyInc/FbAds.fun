Как пользоваться: файл лежит в tools/ репозитория.
Вариант 1 (без сервера): открой файл двойным кликом → «📂 Выбрать папку src/» → укажи папку src.
Вариант 2 (сервер): в корне репо выполни python -m http.server → открой http://localhost:8000/tools/build.html → «🖥 Взять из ./src/».
Готовую кнопку перетащи на панель закладок или скопируй код и создай закладку вручную. Переключатель 🌐 меняет язык устанавливаемой закладки (RU/EN).
